# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do NOT create a public GitHub issue** for security vulnerabilities
2. **Email**: Send details to `contact@seeknay.com`
3. **Include**:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fixes (optional)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 7 days
- **Resolution**: Depends on severity and complexity

## Scope

This security policy applies to:

- The [seeknay-links](https://github.com/pbuffolino/seeknay-links) repository
- The deployed site at [links.seeknay.com](https://links.seeknay.com)

### In Scope

- Cross-site scripting (XSS)
- Exposed secrets or credentials
- GitHub Actions workflow vulnerabilities
- Client-side injection attacks

### Out of Scope

- Rate limiting issues
- Social engineering attacks
- Third-party services (Google Analytics, Font Awesome CDN)
- Denial of Service attacks

## Acknowledgments

We appreciate responsible disclosure and will acknowledge security researchers who help improve this project's security.
